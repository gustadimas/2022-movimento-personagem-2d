# Movimento de Personagem 2D

Projeto da faculdade, de jul/2022. Subi pro GitHub em novembro de 2026 só pra guardar, sem mexer no código.

Um dos primeiros testes que fiz no Unity. O personagem anda, pula só quando está no chão, troca de animação e tem um colisor separado pra quando morre. Está tudo num arquivo só, o `Script.cs`, porque nessa época eu ainda não separava as coisas.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2020.3.36f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
